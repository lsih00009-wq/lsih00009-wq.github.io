حركة بلا مكتبات: transition وtransform

الحركة الجيّدة لا تُرى؛ تُحسّ. زرّ يهدأ بدل أن يقفز، وبطاقة ترتفع درجتين تحت المؤشّر. كلها سطران في CSS، بلا مكتبة ولا ملف يُحمَّل.

بكلمات بسيطة — قبل أي تفصيل

transition تقول: حين تتغيّر هذه الخاصية، لا تغيّرها فجأة — امشِ إليها في نصف ثانية. وtransform تحرّك العنصر أو تكبّره أو تُدوّره دون أن تدفع ما حوله.

الحركة ليست زينة

لما يظهر شيء جديد فجأة، يفقد الزائر مكانه: هل انزلقت الصفحة؟ هل ضغط شيئًا؟ الحركة القصيرة تجيب عن هذا السؤال بلا كلمة. لكن الحركة نفسها تصير ضررًا إذا طالت أو تكرّرت في كل شيء — القاعدة: احرّك ما تغيّر، لا كل ما تراه.

transition: من قيمة إلى قيمة

transition.css
.btn {
  background: #2f6f4f;
  transition: background-color .2s ease;
}

.btn:hover {
  background: #245740;
}

أربعة أجزاء في السطر: الخاصية، والمدّة، ومنحنى السرعة، والتأخير (اختياري). وease تعني «ابدأ سريعًا واهدأ في النهاية» — وهي الأنسب لأغلب الحالات.

  • transition: all — مريحة لكنها تُشغّل حركة على كل خاصية، حتى التي لا تقصدها. اذكر الخاصية.
  • المدّة: بين .15s و.3s للأزرار. أطول من ذلك يبدو بطيئًا.
  • linear تبدو آلية؛ ease-out هي الأقرب للطبيعة.

transform: حركة لا تزحزح أحدًا

لو حرّكت عنصرًا بـmargin فسيدفع ما حوله. أما transform فيحرّكه في مكانه، بلا أن يتأثّر التخطيط — ولهذا هي الأسرع أيضًا.

transform.css
.card {
  transition: transform .22s ease, box-shadow .22s ease;
}

.card:hover {
  transform: translateY(-3px);
  box-shadow: 0 8px 20px rgba(23, 35, 31, .08);
}

.icon { transform: rotate(180deg); }
.zoom { transform: scale(1.05); }

لاحظ -3px بالسالب: في المحور الرأسي، القيمة السالبة ترفع العنصر للأعلى. والفرق بين الرفع درجتين والرفع عشرين أنه في الأول يُحسّ، وفي الثاني يُرى — والأول هو المطلوب.

أيّهما أسرع فعلًا؟

تغيير width أو top يجبر المتصفح على إعادة حساب التخطيط في كل إطار. أما transform وopacity فيرسمهما المعالج الرسومي وحده. لهذا الحركة الناعمة تبدأ من هاتين الخاصيتين.

الحركة ليست لك وحدك

بعض الناس يُصابون بالدوار من الحركة، وقد ضبطوا في أجهزتهم «تقليل الحركة». احترام ذلك سطر واحد:

a11y.css
@media (prefers-reduced-motion: reduce) {
  .card { transition: none; }
  .card:hover { transform: none; }
}

ثلاثة أخطاء تتكرّر

  • الحركة على عنصر لا يظهر: display: none لا يمكن تحريكه — لا وجود له أصلًا. حرّك opacity وtransform بدلًا منه.
  • transform على عنصر سطري: span بلا display: inline-block لا يقبل التحويل.
  • حركة في كل مكان: إن تحرّك كل شيء، لم يعد لشيء معنى. حرّك ما يستجيب للمستخدم فقط.

تمرين: زرّ يهدأ

في المختبر، اصنع زرًّا يغمق لونه عند المرور، ويصغر قليلًا عند الضغط (:active)، ويعود بنعومة. ثم أضف قاعدة «تقليل الحركة» وأغلقها لتتأكد أن الزرّ يبقى يعمل.

حلّ مقترح — افتحه بعد المحاولة
أظهر الحل
press.css
.btn {
  background: #2f6f4f;
  color: #fff;
  border: 0;
  padding: 9px 20px;
  border-radius: 9px;
  cursor: pointer;
  transition: background-color .18s ease, transform .12s ease;
}

.btn:hover  { background: #245740; }
.btn:active { transform: scale(.97); }

@media (prefers-reduced-motion: reduce) {
  .btn { transition: none; }
  .btn:active { transform: none; }
}

جرّب أن ترفع المدّة إلى ثانية كاملة ثم إلى .12s: ستشعر بالفرق قبل أن تقيسه.
