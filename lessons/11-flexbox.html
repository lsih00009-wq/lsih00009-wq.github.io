Flexbox: صفوف وأعمدة بلا معاناة

قبل Flexbox كان توسيط عنصر رأسيًّا مسألة تُسأل في المقابلات. الآن سطران. هذا الدرس يعطيك خمس خصائص تُنجز بها معظم ما ستحتاجه.

الدرس 11متوسط25 دقيقة
في هذا الدرس
بكلمات بسيطة — قبل أي تفصيل

Flexbox طريقة تقول للصندوق: «رتّب أولادك في سطر، ووزّع بينهم المسافة». بدل أن تحسب مكان كل واحد بيدك.

الفكرة: حاوية تحكم أبناءها

تُعلن الحاوية display: flex، فتصبح كل عناصرها المباشرة صفًّا واحدًا يوزّع المساحة بينها. أنت لا تحرّك الأبناء واحدًا واحدًا، بل تقول للحاوية كيف ترتّبهم — وهذا هو الفرق الذهني كله.

flex.css
.row {
  display: flex;
  gap: 12px;
  justify-content: space-between;
  align-items: center;
}
page.html
<div class="row">
  <h2>العنوان</h2>
  <a href="/more">المزيد</a>
</div>

ثلاثة أسطر، فصار العنوان والرابط على طرفَي السطر، متوسّطين رأسيًّا، وبينهما فراغ. لا حساب هوامش، ولا عرض صريح.

المحوران: أصل كل حيرة

Flexbox له محور رئيسي ومحور عرضي، وخصائصه تُسمّى بحسبهما لا بحسب «أفقي ورأسي». لأن الاتجاه قابل للتبديل.

flex-direction: row

الافتراضي. المحور الرئيسي أفقي، فـjustify-content توزّع أفقيًّا وalign-items رأسيًّا.

flex-direction: column

المحور الرئيسي رأسي، فينعكس الدور: justify-content توزّع رأسيًّا.

لحظة الخلاص

إن وضعت justify-content: center فلم يتوسّط العنصر رأسيًّا، فالسبب أن المحور الرئيسي أفقي لا رأسي. تدرّب على السؤال: «أين محوري الآن؟» وستحلّ تسعة من عشرة مواقف بلا حفظ.

خمس خصائص تكفي

the-five.css
.row {
  display: flex;
  flex-wrap: wrap;              /* ١) ينزل لسطر جديد عند الضيق */
  gap: 16px;                    /* ٢) فراغ بين العناصر بلا هوامش */
  justify-content: space-between; /* ٣) توزيع على المحور الرئيسي */
  align-items: center;          /* ٤) محاذاة على المحور العرضي */
}

.row .item {
  flex: 1;                      /* ٥) كل عنصر يأخذ نصيبًا متساويًا */
}
  • gap — أفضل من margin لأنه لا يضيف فراغًا على الأطراف، ولا ينهار.
  • justify-content — flex-start، center، space-between، space-around.
  • align-items — stretch (الافتراضي)، center، flex-start، flex-end.
  • flex: 1 — العنصر يتمدّد ليأخذ المساحة الحرة. وflex: 0 0 200px يعني: لا تتمدد ولا تنكمش، خذ ٢٠٠.

التوسيط الكامل في سطرين

center.css
.hero {
  display: flex;
  align-items: center;
  justify-content: center;
  min-height: 60vh;
}

لاحظ min-height لا height: لو زاد المحتوى على الشاشة الصغيرة، يتمدّد الصندوق ولا يفيض النص خارجه. الفرق بينهما هو الفرق بين تصميم يعمل وتصميم ينكسر في الهاتف.

الالتفاف: حين تكفي المساحة لبعض العناصر

بلا flex-wrap، سيتقلّص الأبناء إلى ما لا يُقرأ بدل أن ينزلوا سطرًا. معه، ينزل الزائد إلى سطر جديد — وهذا هو أساس كل شبكة بطاقات بسيطة:

cards.css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 14px;
}

.cards > * {
  flex: 1 1 240px;  /* لا يقلّ عن ٢٤٠، ويتمدّد إن كان هناك متّسع */
}

أخطاء شائعة

  • ! وضع display: flex على العنصر الذي تريد توسيطه بدل حاويته.
  • ! استخدام margin بين أبناء Flexbox بدل gap، فتحصل على فراغ زائد على الطرف.
  • ! توقّع أن justify-content تعمل رأسيًّا في صف أفقي.
  • ! نسيان flex-wrap ثم الاستغراب من انضغاط البطاقات على الهاتف.

تمرينك الآن

٧ دقائق · بلا مشاهدة حل

ابنِ شريط تنقّل: شعار على اليمين، وثلاثة روابط على اليسار، وكلها متوسّطة رأسيًّا، وبينها فراغ. ثم جرّبه بعرض ٣٦٠ بكسل وتأكد أنه لا ينكسر.

أظهر الحل
nav.css
.bar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  flex-wrap: wrap;
  gap: 10px;
  padding: 12px 16px;
  border-bottom: 1px solid #dfe5d9;
}

.bar nav {
  display: flex;
  gap: 14px;
  flex-wrap: wrap;
}

لاحظ أن الحاوية الخارجية Flex، وأن nav نفسها Flex أيضًا. هذا طبيعي وشائع: الحاويات تتداخل، وكل واحدة لها محورها.

مراجعة سريعة

  1. أين يوضع display: flex؟
  2. في صف أفقي، أي خاصية توزّع أفقيًّا وأيها يحاذي رأسيًّا؟
  3. لماذا gap أفضل من margin هنا؟
  4. ماذا يعني flex: 1 1 240px بكلماتك؟
