أول قاعدة CSS: من يخاطب من؟

CSS ليست «تزيينًا». هي نظام قواعد: كل قاعدة تقول «هذه الفئة من العناصر، هذه صفاتها». أول ما تحتاجه ليس الألوان، بل أن تعرف كيف تصل القاعدة إلى عنصرها.

بكلمات بسيطة — قبل أي تفصيل

CSS قواعد: «كل الفقرات، خطّها كذا». نكتب القاعدة مرة، فتطيعها كل الفقرات. ونضعها في ملف منفصل حتى نغيّر شكل الموقع كله من مكان واحد.

شكل القاعدة

كل CSS، بلا استثناء، مكوّنة من ثلاث قطع:

style.css
p {
  color: #24352c;
  font-size: 16px;
}
p

المحدِّد (selector): مَن أخاطب؟ هنا: كل فقرة في الصفحة.

{ }

كتلة التصريحات: كل ما سأقوله عن هذا العنصر يوضع بينهما.

color: #24352c;

تصريح واحد: خاصية، ثم نقطتان، ثم قيمة، ثم فاصلة منقوطة. لا تنسَ الفاصلة المنقوطة، فهي أكثر سبب للأخطاء الصامتة.

أين تُكتب؟ ثلاث طرق، واحدة صحيحة

ثلاث طرق
<!-- ١) داخلي: داخل وسم الفتح -->
<p style="color: red">نص</p>

<!-- ٢) في الصفحة: داخل head -->
<style>
  p { color: red; }
</style>

<!-- ٣) ملف خارجي: في head -->
<link rel="stylesheet" href="style.css">
  • الداخلي (inline) — أقوى في الأولوية، وأسوأ في كل شيء آخر: يخلط المعنى بالشكل، ويكرّر نفسه، ويستحيل تعديله في عشر صفحات.
  • داخل الصفحة (style) — مقبول لتجربة سريعة، أو لصفحة واحدة خاصة.
  • ملف خارجي — الصواب في كل مشروع حقيقي: المتصفح يحمّله مرة واحدة ويزوره من الذاكرة في بقية الصفحات، وتُعدّل التصميم كله من ملف واحد.
قاعدة عملية

إن وجدت نفسك تكتب style="..." في HTML، اسأل: هل هذه الحالة استثناء واحد في الدنيا؟ إن لم يكن، فمكانه الملف الخارجي. الكود الذي يسهل تعديله هو الكود الذي يعيش.

المحدِّدات: كيف تخاطب عنصرًا بعينه

ثلاثة أنواع تكفي في ٩٥٪ من عملك:

selectors.css
/* ١) باسم العنصر: كل الفقرات */
p { line-height: 1.9; }

/* ٢) بالصنف: أي عنصر كتبت فيه class="note" */
.note { background: #f4f8ec; }

/* ٣) بالمعرّف: عنصر واحد فقط في الصفحة */
#site-title { font-size: 28px; }

/* ٤) بالحالة: الرابط عند مرور المؤشر */
a:hover { color: #3f6b2a; }

وفي HTML يُكتب الصنف هكذا:

index.html
<p class="note">هذه فقرة بتنبيه.</p>
<h1 id="site-title">عنوان الموقع</h1>
الصنف هو أداتك الأساسية

class يُكتب مرة ويُستخدم مئة مرة، ويمكن أن يحمله عنصر واحد أو أكثر، ويمكن للعنصر أن يحمل عدة أصناف: class="note small". ابدأ دائمًا بالصنف، واستخدم المعرّف فقط حين يكون العنصر واحدًا فعلًا.

لماذا لا تُطبَّق قاعدتي؟ (الأولوية)

حين تتعارض قاعدتان على العنصر نفسه، يفوز الأقوى. الترتيب المبسّط:

  1. style داخل الوسم — الأقوى.
  2. المعرّف #id.
  3. الصنف .class وحالات مثل :hover.
  4. اسم العنصر p.

وإن تساوت القوتان، يفوز الأخير في الترتيب. هذا هو معنى «Cascading» في الاسم: الشلال. وأشهر حيرة عند المبتدئ سببها أنه لم يرَ قاعدة أقوى في مكان آخر.

الخصائص التي ستستخدمها كل يوم

  • color — لون النص. وbackground — لون الخلفية.
  • font-size — الحجم، ونفضّل rem على px للنصوص.
  • line-height — ارتفاع السطر. للنص العربي: لا تقلّ عن 1.8.
  • font-family — نوع الخط. ضع خطًّا احتياطيًّا دائمًا.
  • text-align — المحاذاة. في العربية الافتراضي يمين، فلا تغيّره بلا سبب.
ملاحظة عربية تستحق الانتباه

الخطوط العربية تحتاج مساحة رأسية أكبر من اللاتينية لأن حروفها فيها نزول وصعود أكثر. إذا نسخت تصميمًا أجنبيًّا بـline-height: 1.3 فسيلتصق النص ويتنفّس بصعوبة. 1.8 إلى 1.9 مريح للقراءة الطويلة.

أخطاء شائعة

  • ! نسيان الفاصلة المنقوطة، فتُدمج خاصيتان وتُهمل إحداهما بصمت.
  • ! كتابة .note في CSS وid="note" في HTML — لا يتقابلان أبدًا.
  • ! استخدام المعرّفات لكل شيء، فتصبح الأنماط غير قابلة لإعادة الاستخدام.
  • ! نسيان ربط الملف: href="style.css" من داخل مجلد lessons/ يشير إلى ملف غير موجود.
  • ! وضع link في نهاية الصفحة: ستظهر الصفحة بلا تنسيق لحظة ثم تقفز.

تمرينك الآن

٦ دقائق · بلا مشاهدة حل

أنشئ ملفين: page.html وstyle.css. في الصفحة عنوان رئيسي بمعرّف، وفقرة عادية، وفقرة بصنف note، ورابط. اربط الملف، ثم اجعل: النص كله بخط واضح، الفقرات بارتفاع سطر مريح، فقرة note بخلفية فاتحة، والرابط يتغيّر لونه عند مرور المؤشر.

أظهر الحل
style.css
body {
  font-family: "Segoe UI", Tahoma, sans-serif;
  line-height: 1.9;
  color: #24352c;
}

#site-title {
  font-size: 2rem;
}

p {
  font-size: 1rem;
}

.note {
  background: #f4f8ec;
  padding: 12px 14px;
}

a {
  color: #3f6b2a;
}

a:hover {
  color: #111;
  text-decoration: underline;
}

ولاحظ أن .note لم يتعارض مع p: الأول أعطى خلفية، والثاني أعطى حجم خط. القاعدتان اجتمعتا لأن الصفات مختلفة — التعارض لا يحدث إلا حين تتكلم قاعدتان عن الصفة نفسها.
