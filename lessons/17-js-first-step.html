أول سطر JavaScript: زر يغيّر الكلام

حتى الآن صفحتك تتكلّم ولا تسمع. JavaScript هي التي تجعلها تستجيب: تضغط زرًّا، فيحدث شيء. في هذا الدرس ستكتب أول كود يعمل فعلًا — سبعة أسطر فقط.

الدرس 17مبتدئ18 دقيقة
في هذا الدرس
بكلمات بسيطة — قبل أي تفصيل

HTML يقول ماذا يوجد في الصفحة. CSS تقول كيف يبدو. JavaScript تقول ماذا يحدث حين تفعل شيئًا. «حين تضغط هذا الزر، اكتب كلمة أخرى مكان هذه الكلمة» — هذه هي JavaScript في جملة.

الفرق بين الصفحة والصفحة الحيّة

صفحة HTML تشبه ورقة مطبوعة: كل ما فيها موجود قبل أن تلمسه، ولن يتغيّر مهما فعلت. صفحة فيها JavaScript تشبه لوحة إعلانات إلكترونية: تضغط زرًّا فتظهر كلمة جديدة.

JavaScript لغة برمجة — وهذا أول فرق حقيقي بينها وبين الاثنتين السابقتين. HTML وCSS تصفان فقط. أما JavaScript فتستطيع أن تقرّر: «إن كان كذا فافعل كذا»، وأن تكرّر عملًا مئة مرة، وأن تحسب وتعدّ وتخزّن.

لا تحفظ، بل افهم هذه الجملة

كل JavaScript في الدنيا، من ألعاب الفيديو إلى محرّكات البحث، مبنية من ثلاثة أشياء: قيم نحفظها في صناديق، وقرارات (إن كان… فافعل)، وتكرار (كرّر…). إن فهمت الثلاثة، فأنت تفهم اللغة كلها من حيث المبدأ.

أين نكتب الكود؟

كما في CSS، له مكانان. ونستخدم المكان الصحيح من البداية: ملف خارجي بامتداد .js، يُربط قبل إغلاق body مباشرة.

index.html
<body>

  <h1 id="title">مرحبًا</h1>
  <button id="btn">اضغطني</button>

  <script src="assets/app.js"></script>
</body>

ولماذا في النهاية لا في البداية؟ لأن المتصفح يقرأ الملف من أعلاه إلى أسفله. لو وضعت السكربت في الأعلى، سيبحث عن الزر قبل أن يخلق المتصفح الزر نفسه، فلا يجده. وضعُه في النهاية يعني: «انتظر حتى تكون الصفحة جاهزة، ثم ابدأ».

أول تجربة: لوحة الرسائل

قبل أي شيء، جرّب أن تطلب من الصفحة أن تكتب لك رسالة. اكتب في ملف assets/app.js سطرًا واحدًا:

app.js
console.log("مرحبًا، أنا أعمل");

احفظ، ثم افتح الصفحة، ثم اضغط F12 واختر تبويب «Console». ستجد رسالتك هناك. هذه اللوحة هي صديقك الأول في كل عطل قادم: تكتب فيها سطرًا لتعرف قيمة شيء، بدل التخمين.

إن لم تظهر الرسالة

فالمشكلة في الرابط أو المسار — تمامًا كما في الدرس التاسع مع CSS. افتح تبويب «Network»: إن ظهر الملف بالأحمر (404) فالمسار خطأ. لا تُكمل قبل أن تعمل هذه الخطوة، فكل ما بعدها مبني عليها.

الصناديق: let و const

المتغيّر صندوق نضع فيه قيمة ونسمّيه باسم. الاسم من اختيارك، لكن بلا مسافات ولا حروف عربية، ويُفضّل أن يكون معناه واضحًا.

vars.js
let age = 12;              // رقم في صندوق اسمه age
let name = "سالم";          // نص في صندوق اسمه name
const pi = 3.14;           // قيمة لن تتغيّر أبدًا

console.log(age);          // 12
age = age + 1;             // صار 13
console.log(age);          // 13
  • let — صندوق يمكنك تغيير ما فيه.
  • const — صندوق لا يتغيّر. إن حاولت تغييره سيرفض المتصفح، وهذا مفيد: يمنعك من الخطأ.
  • // — كل ما بعده في السطر تعليق لك، لا ينفّذه المتصفح.

التفاعل الأول، سطرًا سطرًا

هذه هي اللحظة المهمة. ستأخذ الزر وتضع عليه «أذنًا تسمع»: كلما ضُغط، نفّذ ما تكتبه.

assets/app.js
// ١) امسك العنصرين من الصفحة باسمهما
const title = document.getElementById("title");
const btn = document.getElementById("btn");

// ٢) علّق على الزر: حين يُضغط، افعل هذا
btn.addEventListener("click", function () {
  title.textContent = "تغيّر الكلام!";
});

لنقرأ كل قطعة، لأن كل كلمة فيها لها سبب:

document

«الصفحة كلها». منه نبدأ حين نريد أن نبحث عن شيء.

getElementById("title")

«أعطني العنصر الذي معرّفه title». ولذلك يجب أن يكون في HTML: id="title".

addEventListener("click", …)

«أضف مستمعًا لحدث الضغط». أي: علّق أذنًا تسمع كلمة click.

function () { … }

«الوصفة التي تُنفَّذ حين يحدث ذلك». نكتبها مرة، وتعمل كل مرة يُضغط فيها الزر.

textContent

«الكلام الموجود داخل العنصر». تغييره يغيّر ما يراه الزائر، لا الشكل.

ثلاثة أخطاء تُكرَّر دائمًا

الأولى: نسيان # ليس هنا بل في CSS — هنا نكتب الاسم كما هو في id بلا علامات. الثانية: كتابة getElementByID بحرف D كبير؛ JavaScript حسّاسة لحالة الأحرف. الثالثة: وضع السكربت قبل العناصر.

اجعله أوضح: عدّاد ضغطات

مثال صغير يجمع كل ما تعلّمته: صندوق، وحدث، وتغيير نص، وحساب.

counter.js
const title = document.getElementById("title");
const btn = document.getElementById("btn");

let count = 0;

btn.addEventListener("click", function () {
  count = count + 1;
  title.textContent = "ضغطت " + count + " مرة";
});

لاحظ "ضغطت " + count: علامة + بين نص ورقم تلصقهما في نص واحد. هذا يُسمّى دمج النصوص، وستستخدمه كثيرًا.

ترتيب التعلّم بعد هذا الدرس

  1. المتغيّرات والأنواع (رقم، نص، صحيح/خطأ).
  2. الشروط: if وelse.
  3. الدوال: كيف تكتب وصفة وتستدعيها.
  4. المصفوفات والكائنات: كيف تحفظ قائمة أو مجموعة صفات.
  5. الحلقات: كيف تكرّر بلا تكرار في الكتابة.
  6. ثم DOM: كيف تغيّر الصفحة بناءً على كل ما سبق.

لا تقفز بينها. من يقفز إلى DOM قبل الشروط يكتب كودًا يعمل مرة واحدة ولا يفهمه.

تمرينك الآن

١٠ دقائق · بلا مشاهدة حل

أنشئ صفحة فيها عنوان بمعرّف msg يحمل كلمة «جاهز»، وزرّان: الأول يكتب «بدأنا»، والثاني يكتب «انتهينا». استخدم دالة واحدة تُستدعى من الزرّين مع نصّ مختلف لكل زر.

أظهر الحل
app.js
const msg = document.getElementById("msg");
const startBtn = document.getElementById("start");
const endBtn = document.getElementById("end");

function changeTo(word) {
  msg.textContent = word;
}

startBtn.addEventListener("click", function () {
  changeTo("بدأنا");
});

endBtn.addEventListener("click", function () {
  changeTo("انتهينا");
});

الفكرة التي تستحق الانتباه: كتبنا changeTo مرة واحدة، واستدعيناها من مكانين. هذا معنى الدالة: وصفة واحدة تُستخدم مرات كثيرة. وإن أردت لاحقًا أن تُضيف تنبيهًا صوتيًّا، تُعدّله في مكان واحد فقط.
