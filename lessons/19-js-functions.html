الدوال والمصفوفات والحلقات

حتى الآن يكتب كودك سطرًا ينفّذ مرة واحدة. هذه الأدوات الثلاث هي التي تجعله يعمل عشر مرات، ومئة، وألف — بلا أن تكتب أكثر.

الدالة وصفة: تكتب خطواتها مرة، وتطلبها باسمها كلما احتجت. والمصفوفة قائمة: تحفظ فيها أشياء كثيرة تحت اسم واحد. والحلقة تقول: «كرّر هذا على كل عنصر في القائمة». الثلاثة معًا تعني أنك لم تعد تكتب الكود، بل تُدير العمل.

الدالة: وصفة لها اسم

تخيّل أنك تشرح لصديق كيف يصنع شايًا. لو شرحتها له كل صباح، ستتعب. الحل: تقول «اصنع الشاي» فيعرف. الدالة هي هذه العبارة القصيرة التي تحمل خطوات مخفيّة.

functions.js
function sayHello(name) {
  console.log("مرحبًا " + name);
}

sayHello("سالم");    // مرحبًا سالم
sayHello("أحمد");    // مرحبًا أحمد
function

الكلمة التي تقول: «سأكتب وصفة».

sayHello

اسم الوصفة. اختيارك، لكن اجعله فعلًا واضحًا.

(name)

المدخل: ما تحتاجه الوصفة لتعمل. يُسمّى «معاملًا»، وهو متغيّر داخلها فقط.

{ … }

الخطوات نفسها. تُنفَّذ فقط حين تُطلب الوصفة.

sayHello("سالم")

«نفّذ الوصفة الآن». ويُسمّى «نداءً» أو «استدعاءً».

فرق يُربك كل مبتدئ

كتابة sayHello بلا أقواس تعني «هذه الوصفة» (نشير إليها ولا ننفّذها). وكتابة sayHello() تعني «نفّذها الآن». ستقع في هذا الفرق مئة مرة، وخاصة حين تربط دالة بحدث: تكتب اسم الدالة بلا أقواس.

الإرجاع: حين تُعيد الوصفة نتيجة

بعض الوصفات لا تُعيد شيئًا، فقط تفعل. وبعضها تُعيد قيمة نستخدمها بعدها:

return.js
function add(a, b) {
  return a + b;
}

const total = add(3, 4);   // 7
console.log(total * 2);    // 14

// اختصار مفيد للدوال القصيرة
const double = (n) => n * 2;
console.log(double(5));    // 10
  • return تُخرج النتيجة وتُنهي الدالة فورًا. أي سطر بعدها لا يُنفَّذ.
  • دالة بلا return تُعيد undefined، أي «لا شيء». وهذا سبب شائع لظهور undefined في صفحتك.
  • السطر const double = (n) => n * 2 يُسمّى دالة سهمية: نفس الشيء بكتابة أقصر.

المصفوفة: قائمة في صندوق واحد

arrays.js
const fruits = ["تفاح", "موز", "عنب"];

console.log(fruits.length);   // 3 — العدد
console.log(fruits[0]);       // تفاح — العدّ يبدأ من صفر!
console.log(fruits[2]);       // عنب

fruits.push("مانجو");          // أضف في النهاية
console.log(fruits.length);   // 4
العدّ يبدأ من صفر

أول عنصر رقمه 0 لا 1. هذا ليس تعقيدًا بلا سبب: العنصر الأول يبعد صفر خطوات عن البداية. احفظها مرة، وستتجنّب أشهر خطأ في الحلقات: أن تبدأ من ١ فتضيع أول عنصر.

الحلقة: كرّر بلا كتابة

لو أردت طباعة كل اسم في قائمة فيها ثلاثون اسمًا، هل تكتب ثلاثين سطرًا؟ الحلقة تكتبها مرة وتقول: «افعل هذا مع كل عنصر».

loops.js
const names = ["سالم", "أحمد", "سارة"];

// ١) الطريقة الحديثة والأسهل
names.forEach(function (name) {
  console.log("مرحبًا " + name);
});

// ٢) الحلقة التقليدية: عداد يبدأ من صفر
for (let i = 0; i < names.length; i++) {
  console.log(i + " - " + names[i]);
}
let i = 0

ابدأ العدّ من صفر.

i < names.length

استمر ما دام العدد أقل من طول القائمة. حين يصبح مساويًا، توقف.

i++

زد واحدًا في كل دورة. بلا هذا السطر تدور الحلقة إلى الأبد ويتجمّد المتصفح.

map و filter: أقوى أداتين لقائمة

map-filter.js
const prices = [100, 250, 60, 400];

// map: حوّل كل عنصر إلى شيء آخر
const withTax = prices.map(function (p) {
  return p * 1.15;
});
console.log(withTax);   // [115, 287.5, 69, 460]

// filter: احتفظ بالعناصر التي تحقق شرطًا
const big = prices.filter(function (p) {
  return p > 100;
});
console.log(big);       // [250, 400]

الاثنتان لا تُغيّران القائمة الأصلية، بل تُعيدان قائمة جديدة. وهذا فرق مهم: الأصل يبقى سليمًا، وأنت تبنى منه نسخة معالجة. الفكرة نفسها ستقابلك في كل مكان بعد اليوم.

تجميع الثلاثة: جدول من قائمة

students.js
const students = [
  { name: "سالم", score: 82 },
  { name: "أحمد", score: 45 },
  { name: "سارة", score: 91 }
];

// من نجح فقط، بأسمائهم
const passed = students
  .filter(function (s) { return s.score >= 50; })
  .map(function (s) { return s.name; });

console.log(passed);   // ["سالم", "سارة"]

// متوسط الدرجات
let sum = 0;
students.forEach(function (s) {
  sum = sum + s.score;
});
console.log(sum / students.length);   // 72.6

لاحظ أن { name: "سالم", score: 82 } كائن: مجموعة صفات لشيء واحد. والقائمة كائنات تعني «جدول بيانات» — وهذا هو الشكل الذي ستستخدمه في كل تطبيق حقيقي: قائمة مهام، قائمة منتجات، قائمة رسائل.

أخطاء شائعة

  • ! نسيان return داخل map، فتصبح كل القيم undefined.
  • ! بدء الحلقة من ١ بدل ٠.
  • ! نسيان i++، فال حلقة لا تنتهي ويتوقف المتصفح.
  • ! الاعتقاد أن filter تحذف من الأصل — هي تُعيد قائمة جديدة.
  • ! اسم دالة يبدأ برقم أو يحتوي شرطة: my-func خطأ، myFunc صحيح.

تمرينك الآن

١٢ دقيقة · بلا مشاهدة حل

عندك قائمة مشتريات: ["خبز", "لبن", "جبن", "شاي"]. اطبع كل عنصر مع رقمه بدءًا من ١، ثم اطبع فقط العناصر التي تحتوي حرف «ش»، ثم اطبع العدد الكلي.

أظهر الحل
shopping.js
const items = ["خبز", "لبن", "جبن", "شاي"];

// ١) مرقّمة من واحد
items.forEach(function (item, index) {
  console.log((index + 1) + ". " + item);
});

// ٢) التي تحتوي حرف الشين
const withSheen = items.filter(function (item) {
  return item.includes("ش");
});
console.log(withSheen);   // ["شاي"]

// ٣) العدد
console.log(items.length);  // 4

لاحظ index + 1 في الطباعة: الفهرس يبدأ من صفر، والبشر يبدأون من واحد، فنضيف واحدًا عند العرض فقط. هذه عادة ستتكرّر معك كثيرًا.
