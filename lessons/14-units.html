الوحدات: px و rem و % و vh

لماذا يبدو موقعك جامدًا حين يكبّر المستخدم الخط؟ الجواب في الوحدات. هذا الدرس قصير لكنه يغيّر كل ما كتبته قبلًا.

الوحدات مثل المساطر: البكسلات مسطرة ثابتة، وrem مسطرة تتغيّر مع حجم خط القارئ. إن استخدمت rem، كبرت صفحتك لمن يكبّر الخط فلا يتعب.

نوعان: مطلق ونسبي

الوحدات المطلقة ثابتة لا تتغيّر: px. والوحدات النسبية تُحسب من شيء آخر: من حجم خط الجذر، أو من حجم الأب، أو من الشاشة. والفرق بينهما ليس تجميليًّا: إنه الفرق بين موقع يحترم إعدادات القارئ وموقع يتجاهلها.

الوحدات التي تحتاجها فعلًا

rem

مضاعف حجم خط الجذر (16px افتراضيًّا): 1rem = 16، و1.5rem = 24. لو غيّر المستخدم حجم خط المتصفح، كبرت كل صفحتك معه. للنصوص والمسافات.

em

مضاعف حجم خط الأب. مفيد داخل مكوّن يريد أن يتناسب مع نصّه، لكنه يتراكم في التداخل ويصير محيّرًا. لا تبدأ به.

%

نسبة من الأب. للعروض داخل حاوية معروفة.

fr

كسر من المساحة الحرّة داخل Grid. لا تُستخدم خارج الشبكات.

vw / vh

١٪ من عرض/ارتفاع نافذة العرض. احترس من vh في الهاتف، وdvh أدقّ حين يتوفّر.

ch

عرض المحرف «0». سحرية لعرض عمود نص: max-width: 65ch يعطي طول سطر مريحًا للقراءة.

قاعدتان تكفيان

الاختصار الذهني

للنصوص والمسافات: rem. للأبعاد داخل حاوية: % أو fr. ولا تستخدم px إلا للحدود (1px) والزوايا الصغيرة. هذه القاعدة وحدها تجعل تصميمك محترمًا لمن يكبّر الخط، وهم كثيرون أكثر مما تظن.

units.css
:root {
  font-size: 100%;      /* يحترم إعداد المستخدم */
}

body {
  font-size: 1rem;      /* 16px */
  line-height: 1.9;
}

h1 { font-size: clamp(1.5rem, 4vw, 2.5rem); }

.card {
  padding: 1rem 1.25rem;
  border: 1px solid #dfe5d9;
  border-radius: 10px;
  max-width: 65ch;
}
خطأ شائع جدًّا

كتابة html { font-size: 62.5% } لتسهيل الحساب (1rem = 10px). هذا مظهر ذكي لكنه يكسر توقّعات من يكبّر الخط في متصفحه، وتضطر بعدها إلى تعويض ذلك بيدك. اترك الجذر 100٪ واحسب: 0.875rem = 14px.

حساب سريع في رأسك

  • 0.875rem = 14px
  • 1rem = 16px
  • 1.25rem = 20px
  • 1.5rem = 24px
  • 2rem = 32px

وإن أردت أن تعرف الرقم بالعكس: اقسم البكسلات على ١٦. لا تحتاج آلة حاسبة، فقط تدرّب أسبوعًا وستحفظ الخمسة الأوائل.

طول السطر: أهم رقم لا يعرفه المبتدئون

السطر الطويل جدًّا يُتعب العين لأنها تفقد مكانها عند الرجوع. المدي المثالي للقراءة الطويلة بين ٤٥ و٧٥ محرفًا. في CSS:

reading.css
.prose {
  max-width: 68ch;
  margin-inline: auto;
}

وmargin-inline تعني «الهامش في اتجاه السطر» — في العربية يمين ويسار. وهي أفضل من margin: 0 auto لأنها لا تفترض الاتجاه.

أخطاء شائعة

  • ! كل شيء بـpx، فيصبح الموقع جامدًا أمام تكبير الخط.
  • ! استخدام 100vh لقسم كامل، فتظهر مسافة أو قصّ في الهاتف.
  • ! نصوص بعرض الشاشة كاملة على الحاسوب: سطر من ١٤٠ محرفًا لا يُقرأ.
  • ! الاعتماد على em متداخلًا، فتصل إلى 0.7em داخل 0.8em داخل 0.9em بلا أن تدري.

تمرينك الآن

٥ دقائق · بلا مشاهدة حل

حوّل ملف CSS من الدرس التاسع إلى rem: النص الأساسي 1rem، العناوين بـclamp، الحشو بـrem، وعرض المقالة ٦٥ محرفًا. ثم كبّر الخط في المتصفح إلى 150٪ ولاحظ الفرق.

أظهر الحل
style.css
body {
  font-size: 1rem;
  line-height: 1.9;
  color: #24352c;
}

h1 { font-size: clamp(1.6rem, 4vw, 2.6rem); }
h2 { font-size: clamp(1.25rem, 3vw, 1.75rem); }

p {
  max-width: 65ch;
  margin-inline: auto;
}

.note {
  padding: 0.9rem 1.1rem;
  border-inline-start: 3px solid #7aa85c;
}

الآن كبّر خط المتصفح: كل شيء يكبر متناسبًا، ولا يبقى نص صغير معلّقًا. هذا هو معنى «موقع يحترم قارئه».

مراجعة سريعة

  1. ما الفرق الجوهري بين px وrem؟
  2. متى تستخدم ch، وما الرقم المريح للسطر؟
  3. لماذا نتجنّب 100vh في الهاتف؟
  4. ما خطأ html { font-size: 62.5% }؟
