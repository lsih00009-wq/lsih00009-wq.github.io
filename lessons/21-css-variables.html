متغيّرات CSS: لون واحد يغيّر الموقع

تخيّل أنك كتبت اللون نفسه في أربعين مكانًا، ثم أردت تغييره. هذا الدرس يعطيك اسمًا للقيمة بدل أن تكرّرها: تغيّره في سطر واحد، فيتغيّر في كل مكان.

المتغيّر صندوق له اسم، تضع فيه قيمة (لون، قياس، ظل). تكتب القيمة مرة واحدة، ثم تستعمل الاسم في كل مكان. وإن أردت تغييرها لاحقًا تغيّر ما في الصندوق فقط، وكل من يستعمل الاسم يتغيّر معك.

المشكلة قبل الحل

اكتب صفحة صغيرة فيها زرّان وعنوان وفقرة. الآن أعطِ العنوان لونًا، والزرّين اللون نفسه، والفقرة لونًا ثالثًا. ثم قرّر أن اللون الأساسي صار باهتًا على الشاشات. كم سطرًا ستُعدّل؟ أربعة الآن، وأربعون في موقع كامل — وفي كل مرّة تنسى واحدًا.

before.css
h1 { color: #2f6f4f; }
.btn { background: #2f6f4f; }
.badge { border-color: #2f6f4f; }
.link { color: #2f6f4f; }

ولاحظ الخطر الأكبر: التكرار لا يخطئ مرة واحدة، بل يخطئ بصمت. يبقى زرّ واحد باللون القديم في صفحة نادرًا ما تفتحها، فلا تراه إلا يوم الإطلاق.

كيف تُعلن متغيّرًا

المتغيّر في CSS يُكتب بشرطتين قبل الاسم: --brand. ويُعلَن داخل محدِّد كأي خاصية أخرى، ويُقرأ بـvar().

variables.css
:root {
  --brand: #2f6f4f;
  --ink: #17231f;
  --paper: #f3f6ee;
}

h1 { color: var(--brand); }
.btn { background: var(--brand); color: var(--paper); }
.link { color: var(--brand); }

الآن تغيير اللون كله سطر واحد: --brand في :root. و:root تعني «أعلى شجرة الصفحة»، أي أن المتغيّر يرثه كل عنصر تحته — لذلك نضع فيه الألوان والقياسات العامة.

لماذا شرطتان وليس كلمة var؟

لأن الأسماء العادية محجوزة لخصائص CSS. الشرطتان تقولان للمتصفح: هذا اسم اخترعته أنت. ولهذا تُقرأ بـvar(--brand) وليس --brand وحده.

الوضع الغامق: المتغيّر يفتح بابًا

هنا تظهر الفائدة الحقيقية. بدل أن تكتب ثيمًا ثانيًا لكل عنصر، تُغيّر قيم المتغيّرات نفسها حين يضيف المتصفح سمة على html:

theme.css
:root {
  --paper: #f3f6ee;
  --ink: #17231f;
}

html[data-theme="dark"] {
  --paper: #0e181d;
  --ink: #e8f0e9;
}

body {
  background: var(--paper);
  color: var(--ink);
}

سطر JavaScript واحد يضيف data-theme="dark" إلى html، وكل ما في الصفحة يتبدّل. لم نلمس عنصرًا واحدًا بعينه — لأن العناصر لا تعرف الألوان، بل تعرف أسماءها.

الخطأ الذي يوقع كل مبتدئ

أن تكتب color: --brand; بلا var(). لا رسالة خطأ، ولا لون — فقط نصّ يبقى كما هو. القاعدة: الإعلان بشرطتين، الاستخدام بـvar().

قيمة احتياطية

var() تقبل قيمة ثانية بعد فاصلة، تُستعمل إن كان الاسم غير معرَّف:

fallback.css
.card {
  border: 1px solid var(--line, #d9e2d0);
  border-radius: var(--radius, 12px);
}

هذه ليست تفصيلة صغيرة: صفحة تعمل قبل أن تكتب متغيّراتها كلها خير من صفحة بيضاء لأن اسمًا واحدًا نُسي.

حدود المتغيّر

  • لا يعمل داخل اسم خاصية، بل في قيمتها فقط: var(--side)-color لا تصحّ.
  • المتغيّر موروث: إن أعلنته داخل .card فلن تراه العناصر خارجه.
  • لا يستبدل CSS: هو للقيم المتكرّرة، لا لكل قيمة. قيمة تُستخدم مرة واحدة تُكتب مرة واحدة.

تمرين: ثلاثة ألوان، سطر واحد

في المختبر، اكتب بطاقة فيها عنوان ونصّ وزرّ. أعطِ الثلاثة لونًا من متغيّر واحد اسمه --brand، ثم غيّر قيمته مرّة واحدة وراقب ما يحدث.

حلّ مقترح — افتحه بعد المحاولة
أظهر الحل
card.html
<div class="card">
  <h2>عنوان البطاقة</h2>
  <p>سطر يشرح الفكرة في جملة واحدة.</p>
  <a class="btn" href="#">اقرأ</a>
</div>
card.css
:root { --brand: #2f6f4f; }

.card { border: 1px solid var(--brand); border-radius: 12px; padding: 16px; }
.card h2 { color: var(--brand); margin: 0 0 6px; }
.btn { background: var(--brand); color: #fff; padding: 6px 14px; border-radius: 8px; }

/* غيّر هذا السطر وحده، ثم راقب الثلاثة */
:root { --brand: #b4552a; }

لاحظ أن السطر الأخير يعيد تعريف الاسم نفسه — ولهذا يفوز: التعريف الأحدث يغلب عند التساوي.
