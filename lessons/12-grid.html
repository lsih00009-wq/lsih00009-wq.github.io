Grid: شبكة حقيقية للصفحة

Flexbox يرتّب في اتجاه واحد. Grid يرتّب في اتجاهين معًا: أعمدة وصفوف. تخطيط صفحة كاملة يصير عشرة أسطر تُقرأ كخريطة.

بكلمات بسيطة — قبل أي تفصيل

Grid شبكة مثل رقعة شطرنج: تقول «ثلاثة أعمدة»، فتضع الأشياء في خاناتها. للصفحات الكبيرة.

أيّهما أختار؟

هذا السؤال يُسأل كثيرًا، وجوابه بسيط:

  • Flexbox — حين تكون العناصر في سطر واحد وتريد توزيع المساحة بينها. شريط تنقّل، أزرار، بطاقة واحدة بمحتواها.
  • Grid — حين يكون لديك صفوف وأعمدة معًا، وتريد تحكّمًا في الاثنين. تخطيط صفحة، معرض صور، لوحة معلومات.

وهما لا يتنافسان: أكثر التخطيطات الحقيقية تستخدم الاثنين، شبكة للصفحة وFlexbox داخل كل خلية.

أول شبكة: أعمدة بقيم ثابتة

grid.css
.layout {
  display: grid;
  grid-template-columns: 200px 1fr;
  gap: 20px;
}

هذا سطران يعطيانك تخطيطًا بمحتوى رئيسي وشريط جانبي. العمود الأول ٢٠٠ بكسل، والثاني 1fr أي «الجزء المتبقي كله». وfr اختصار fraction: كسور المساحة الحرّة.

fr أذكى من النسبة المئوية

grid-template-columns: 2fr 1fr يعطي الثلثين للعمود الأول والثلث للثاني، ويحسب ذلك بعد خصم الفراغات. أما 66% 33% فتنكسر عند إضافة gap لأن النسب لا تعرف شيئًا عن الفراغ بينها.

repeat و minmax: الشبكات المتجاوبة بلا media query

أكثر ما ستحتاجه هو شبكة بطاقات تتغيّر أعمدتها حسب عرض الشاشة. هذا السطر يفعلها وحده:

cards.css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 16px;
}
repeat()

تختصر تكرار القالب. repeat(3, 1fr) = ثلاثة أعمدة متساوية.

auto-fit

«ضع أكبر عدد ممكن من الأعمدة في السطر». على الهاتف عمود واحد، وعلى الشاشة الكبيرة أربعة — بلا كود إضافي.

minmax(240px, 1fr)

كل عمود لا يقلّ عن ٢٤٠ ولا يزيد على نصيبه من المساحة. الـ٢٤٠ هي الحدّ الذي يمنع البطاقة من الانضغاط.

auto-fit أم auto-fill؟

الفرق يظهر حين تكون البطاقات قليلة: auto-fill يُبقي الأعمدة الفارغة فتبقى البطاقات بعرضها الأدنى، وauto-fit يطويها فتتمدّد البطاقات لتملأ السطر. في تسعة من عشرة أعمال تريد auto-fit.

تخطيط الصفحة بالاسم

أقوى ما في Grid أنك تكتب التخطيط كما تراه في ذهنك:

page.css
.page {
  display: grid;
  grid-template-areas:
    "head head"
    "side main"
    "foot foot";
  grid-template-columns: 220px 1fr;
  gap: 18px;
}

.page > header { grid-area: head; }
.page > aside  { grid-area: side; }
.page > main   { grid-area: main; }
.page > footer { grid-area: foot; }

الشكل مكتوب أمامك حرفيًّا: الرأس يمتد على العمودين، والجانب والمحتوى في الوسط، والتذييل يمتد على الاثنين. من يقرأ هذا الملف يعرف التخطيط دون تجربته في المتصفح.

أخطاء شائعة

  • ! استخدام Grid لسطر أزرار واحد — Flexbox أبسط وأوضح.
  • ! نسيان gap ثم إضافة هوامش لكل خلية يدويًّا.
  • ! كتابة auto-fill ثم الاستغراب من بقاء فراغ في آخر السطر.
  • ! ضبط أعمدة بـpx ثابتة، فتنكسر الشبكة على الهاتف.

تمرينك الآن

٨ دقائق · بلا مشاهدة حل

ابنِ شبكة بطاقات لستّ مقالات، بحيث تتغيّر الأعمدة تلقائيًّا: عمود على الهاتف، وعمودان على التابلت، وثلاثة على الشاشة الكبيرة. بلا media query واحدة.

أظهر الحل
articles.css
.articles {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 18px;
}

.articles article {
  border: 1px solid #dfe5d9;
  border-radius: 12px;
  padding: 16px;
  background: #fff;
}

حاول أن تتنبّأ قبل التجربة: على شاشة ٣٦٠ بكسل، هل تسمح الـ٢٦٠ بعمودين؟ الجواب لا، لأن ٢×(٢٦٠ + فراغ) أكبر من ٣٦٠. المتصفح سيضع عمودًا واحدًا تلقائيًّا.
